# 主动陪伴与侧置摄像头

本次升级在原有本地视觉、学习计时与DeepSeek对话上增加主动调度、个人视角校准、行为片段和学习复盘。检测描述可观察动作，不推断情绪、真实注意力或知识掌握。

## 使用顺序

1. 开启学习计时，在学习面板设置主动关怀间隔，默认60分钟。摄像头可独立开关。
2. 打开视觉陪伴，按平常坐姿和学习朝向完成自然姿态校准；镜头在侧面时同样保持平常朝向，不需要为了校准临时转向摄像头。
3. 做皱眉动作校准，确认两种状态能被区分，再应用推荐阈值。若无法区分，调整光照、距离或镜头位置后重试。校准数据仅为数值摘要。
4. 选择电脑、纸质阅读／写题或混合学习方式。低头是姿态线索，不能等同于玩手机或开小差。
5. 每轮结束后，进入学习记录的学习小结，查看本轮事实、关联问答并补充完成情况；当天汇总按日期查看。
6. 需要模型复盘时，明确勾选发送选中范围的文字与统计，再点击生成。这里只发送必要文字与摘要，不发送摄像头图像。

## 侧脸与无法判断

正常学习朝向被保存为头部角度基线；低头比较的是相对这个基线的变化。远侧眉部可见性不足时降低其权重；明显偏离校准视角、眉眼遮挡、模糊、过暗等情况停止使用眉部证据。

没有检测到脸并不能证明离位。系统先建立原工位人体关联；可靠人体仍在时可辅助在位判断。无法确认归属、多人或画面失效时保存未知状态；只有持续可靠阴性证据才确认离位。人体检测也不提供身份认证或活体防伪。

## 主动提醒与学习记录

学习累计跨轮次保留；短暂暂停、换任务和关闭摄像头不会被当成完整休息。显式休息达到设定时长后才清零。中途休息保留原轮次和剩余时间，休息结束由用户继续；提前结束休息先恢复原任务的暂停状态。

行为检测与提醒分别处理。隐藏桌宠、勿扰、冷却或关闭气泡不改变已开启的行为统计。记录开关关闭期间不落库，也不在重开后补造记录。持续同一行为使用稳定片段ID；短暂信号未知冻结累计，未知时间不算行为持续时间。

学习记录保存计时投入、可观测在位、离位、画面未知和未观测时间。手机、低头、眉部行为可能重叠，不能简单相减得到真实专注时长。提醒只引用行为片段，提醒次数不代表行为次数。

每条问答在发送时固定学习轮次，生成期间切换任务也不改归属。本地小结自动保存，模型复盘是可选操作。模型只提炼完整问答中的知识点及建议，数字来自本地程序；对话来源ID和事实版本用于阻止旧结果覆盖新统计。

## 验证范围

自动测试覆盖个人侧视基线、质量拒判、短暂缺失、片段去重、多人保护、模型结果时效、休息恢复、消息归属、数据库升级、跨日分配、误报反馈以及模型失败降级。公开图片用于验证真实模型推理与特征提取链路；集成预览使用明确的合成测试数据，不访问真实摄像头、真实聊天或付费接口。

实际摄像头识别率仍需针对目标设备与用户采集独立标注片段评估。应包括正面和左右侧置、低头写字、纸书阅读、自然思考、眯眼、眼镜反光、手机查资料、多人经过和摄像头遮挡。分别报告事件查准率、查全率、每小时误提醒、有效覆盖率及延迟，不能用大量正常帧的总体准确率替代。
