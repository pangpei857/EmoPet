# 雨衣皮卡丘学习桌宠

以用户提供的雨衣皮卡丘插画为角色贴图，透明悬浮，可以用鼠标互动、拖动和缩放，并陪伴学习计时。

## 直接运行

在本项目文件夹双击 **启动桌宠.cmd**。如果已有打包版，启动器会优先运行 `dist/Momo/Momo.exe`。

- 在学习面板输入任务，选15、25、45分钟，或自定义1—120分钟，然后点“开始专注”。
- 点击头部：闭眼享受摸头、飘出爱心；点击肚子：轻轻扭动；点击闪电尾巴：摆尾和星星回应。
- 移动鼠标：睁眼时原画的棕色眼睛平滑看向鼠标，上下左右都可跟随；鼠标移到肚子、脚下或桌宠窗口外也会持续跟随，缩放和拖动后仍然有效。悬停时角色轻轻摇晃回应。
- 按住左键拖动：移动桌宠，接近屏幕边缘会吸附；拖动不会再触发点击。
- 在皮卡丘身上滚动滚轮：以10%调整大小，范围70%—160%；右键和托盘菜单也可选择大小。
- 双击皮卡丘或点击脚下状态条：打开学习面板；气泡右上角可以直接关闭。
- 可以暂停、继续、结束本轮。完成后气泡会提醒休息，并可开始5分钟休息。
- 关闭学习面板会继续计时；右键桌宠和托盘菜单提供互动动作、隐藏／恢复、置顶、缩放和退出；面板内按Ctrl+Q也可退出。
- 启动时先显示桌宠，双击再打开学习面板。单击托盘图标恢复桌宠，双击托盘图标打开面板。
- 右键或面板右上角“桌宠设置”可锁定位置、开关气泡、找回桌宠。锁定后仍可点击互动和滚轮缩放。
- 隐藏后不会被普通提醒自动唤回；隐藏会取消尚未触发的点击反馈。
- 长气泡会折行，最多显示6行，悬停可查看完整内容，阅读期间暂停自动关闭；气泡变高和切换置顶时保持角色脚下的位置。
- 屏幕可用区域改变后会自动检查位置和大小，“找回桌宠”可将其放回主屏幕右下角。
- 今日专注时长、完成轮数、位置、大小、位置锁定、气泡和置顶状态保存在Windows本地应用数据的 `Momo/MomoStudyPet` 目录。

## 动作与反馈

| 动作 | 表现 | 触发方式 |
| --- | --- | --- |
| 待机 | 呼吸、眨眼、耳朵和尾巴轻摆、眼睛跟随鼠标 | 默认或点击“待机” |
| 关心 | 雨衣角色歪头、爱心 | “关心我”、暂停或结束本轮 |
| 提醒 | 轻跳、耳朵摆动、小闹钟 | “提醒我”、学习／休息计时结束 |
| 鼓励 | 闭眼、跳跃、旋转星星 | “为我加油”、开始学习或继续 |

动作会自动回到当前学习或休息状态，休息时闭眼安静陪伴。原始贴图位于 `assets/raincoat-reference.png`，保持原文件不变，由程序在显示时裁掉原图中的棋盘格与枫叶，并为耳朵、尾巴和眼睛添加动画。本版使用预设鼓励语，尚未接入摄像头、麦克风、自动行为识别或AI聊天。

## 开发运行

使用64位Python 3.11或3.12创建环境，安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
```

本次开发环境使用Python 3.12。桌宠只需要Qt的Essentials组件，暂不安装视觉、音频和大模型依赖。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --smoke-test --preview-path .artifacts/mvp-preview.png
.\.venv\Scripts\python.exe tools/render_assets.py
.\.venv\Scripts\python.exe main.py --profile-dir .artifacts/desktop-qa-profile
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

打包结果为 `dist/Momo/Momo.exe`，分发时应复制整个 `Momo` 文件夹。第三方库的许可文件应随完整文件夹保留。

## 代码入口

- `main.py`：启动、单实例和界面冒烟验证。
- `study_pet/focus.py`：独立的计时逻辑，采用单调时间，避免界面卡顿造成计时漂移。
- `study_pet/ui.py`：桌宠、学习面板、托盘与交互。
- `study_pet/pikachu.py`：角色动作、鼠标分区与手势。
- `study_pet/raincoat.py`：原画贴图、透明轮廓、耳朵与尾巴分层、眼睛纹理跟随。
- `study_pet/storage.py`：本地设置和当日计时摘要。
